# 工时榨汁机 · 英寸照妖镜 · 铁件点钞机

Gongshi · Net Hours（Squeeze out the breaks. Keep the real hours.）和 Yingcun · Inch Converter（Point it at the sheet. Inches confess in millimeters.）。

三个车间小工具，页面顶上一点就互相切换。版本 0.4.1。

打开：https://qianshoulab.github.io/gongshi/

## 中英两套

- 默认英文，右上角 EN / 中文 切换，选过就记住（两页共用，存在这台手机上）；网址加 `?lang=zh` / `?lang=en` 只管这一次。不跟浏览器语言走。
- 两页给人看的字都在根目录 `strings.js`（en、zh 各一套），改字只改那里；版本号也在那里。
- 自查：`node docs/bi-check.js`（要 playwright），导出 `docs/strings-bi/zh.txt`、`en.txt`，中英各跑一遍真流程、查英文排版，截图到 `docs/shots-bi/`。

## 工时榨汁机

换型实际时间计算器：填开始和结束时间，自动扣掉和这段时间重叠的休息（10:00–10:10、15:00–15:10）、午饭（11:30–12:10）、晚饭（18:00–18:30），跨天时跳过下班到次日上班（20:30 → 08:15）。

休息表可以改：点「改休息表」，在表里直接改每段的起止和名字、加一段、删一段，上下班时间也能改；改了马上算数，存在这台手机上（换手机要重新改），「恢复默认」回到上面那套。几段休息叠在一起时，同一分钟只扣一次。

## 英寸照妖镜

打开：https://qianshoulab.github.io/gongshi/inch/

拍检查表（IN-PROCESS INSPECTION REPORT 这类），尺寸（DIMENSION）、公差（LSL / USL）、控制范围（LCL / UCL）的数字在原图上落红字换算值：

- 快门是一面照妖镜：镜面一按就开相机；镜框是先天八卦 + 仿汉镜铭文「见寸之光，毫厘大明」，外圈法阵慢慢转；镜子周围的藤蔓（叶、卷须、发光的果子、萤火）全是同一个蓝，远近只靠饱和度和亮度分；打开时从镜子里长出来，识别时镜框转快、镜面扫光
- 两种模式：英寸 → 毫米（× 25.4，留 3 位）、毫米 → 英寸（÷ 25.4，留 4 位），记住上次选的
- 照片横拍、倒拍、歪拍都行，自动扶正、拉平透视，从「标号」裁到「UCL」；加工余量是 0 不动，不是 0 也换
- 图宽，手机横过来看字大一倍多；竖着看也能双指放大
- 自动对账：尺寸 + 下差 = LCL、尺寸 + 上差 = UCL（有加工余量时允许 ± 余量），对上的放心看，对不上的那一对标黄
- 点红字能改认错的原数；对不上账时会给出倒推的值（公差按 LCL/UCL 倒推，控制范围按尺寸和公差算），点「用这个」就填上
- 红字各自从原数换算：比如 UCL 27.610 是 1.0870 × 25.4，不是 27.584 + 0.025，两者差 0.001 是四舍五入
- 认不出表头时，照片里所有纯数字（含 3/8、1-1/4 这类分数）全部换算；螺纹规格这类不是纯数字的不动
- 识字全在手机本地跑，照片不上传；第一次打开下载约 30 MB 识字模型，之后断网也能用

用到的东西：PaddleOCR PP-OCRv4 识字模型（Apache-2.0，ONNX 版来自 RapidOCR）、onnxruntime-web 1.31.1（MIT）。

## 铁件点钞机

打开：https://qianshoulab.github.io/gongshi/count/

拍一盘工件，数量直接出来。

长相（0.4.0，一台点钞机）：夜色群青的底，背后几团蓝、粉、紫的光（颜色取自 Song 给的海报，样子是 App 不是海报）。上面是机身面板：四颗螺丝、六角图标、「千手院出品 / 铁件点钞机」铭牌、状态灯（待机 / 点钞中 / 完成 / 卡钞了）、一块绿色七段数码管。中间是取景器：没拍的时候里面一只托盘自己演示点数，拍了就换成照片。快门是一条浮在屏幕底下的玻璃，紫色滚花旋钮从上沿冒出来，左相册右设置；拍完不用往回翻。数的时候数码管一段一段转圈，数完从 0 跑到总数、圆点一排一排亮。存图底下接一块数码管面板。

- 规矩：只数一盒；第二盒完整拍进来才一起数。贴着照片边的盒子一律算没拍全；主盒没拍全也照数，但标黄提醒看边上
- 每盒旁边有「不算 / 也算上」，判错了自己翻
- 照片上每个数到的件盖一个糖果圆点：点圆点删掉，点漏掉的件补一个，数字跟着变，右边标「手改 +n −n」
- 存图：照片 + 圆点 + 底下一条海报数字和时间，手机上直接弹分享（存相册）
- 数数的是谷歌 Gemini。不填钥匙：走 Song 的中转站（QIANSHOULAB/luruseng-relay 的 /count，钥匙锁在 Cloudflare Secret；先 gemini-3.8-flash，额度没了换 gemini-3.5-flash-lite），大伙共用每天的免费额度；额度吃干了弹出钥匙抽屉，贴自己的钥匙接着数
- 自己的钥匙存在手机上，网址 ?key= 带过去；默认先 gemini-3.8-flash，额度没了或这把钥匙用不了就换 gemini-3.5-flash-lite；不用 2.5（新钥匙用不了），钥匙 2 是备胎；出错原样显示谷歌回的 HTTP 状态和 message
- 照片发给谷歌去数，本页不存
